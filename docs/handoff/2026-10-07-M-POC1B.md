## Ograniczenia i koszt

Pełny podział atomowy, kompletny graf i wszystkie małe napisy/ratings grafiki
nie są potwierdzone. Zewnętrzne cele, aliasy, scenariusze i mapy nadal wymagają
konkretnego ograniczonego kontekstu. Lokalny rachunek/warunek nie jest pełną
legalnością ruchu lub wynikiem całego combat. Source-supported Codex proposal
nie oznacza akceptacji właściciela. Mianowniki potwierdzone i niepotwierdzone,
jawne i niejawne rozdzielono; precision/recall nieocenialne przed freeze/próbą.

Proponowana kompozycja 16/20 wyników lokalnych nie jest osiągnięciem progu
jakości POC; właściciel musi ocenić użyteczność tego zakresu przed zamrożeniem.
Nie zmieniać oczekiwań według przyszłej odpowiedzi.

Model widoczny w selektorze, poziom reasoning, aktywny czas właściciela/modelu,
tokeny i cena: unknown. Czas kalendarzowy części z odczytów zegara zapisany
w measurement; bootstrap poprzedza pierwszy zapis zegara. Nie przypisano
proponowanej konfiguracji jako faktycznie użytej. Sesja oceny widziała klucz,
nie może być ślepą pierwszą ekstrakcją.

Bez API inferencji, GUI, innych czatów lub wiadomości, zmian innych repozytoriów,
importów kodu/schematów legacy, reset/clean/stash/commit/push lub globalnej
konfiguracji Git. Zastane zmiany po archiwizacji zachowano. M-DESK2 pozostaje
historycznie partial poza aktywną kolejką. Ostrzeżenie dostępu do globalnego
ignore Git nie zostało usunięte zmianą konfiguracji.
