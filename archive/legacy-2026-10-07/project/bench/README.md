# Benchmark

Opis modelu jakości i metryk: [docs/QUALITY.md](../docs/QUALITY.md).

- `minigame/rulebook.md`: **Drill Skirmish**, własna instrukcja (CC0). Każda reguła ćwiczy co najmniej jedno zjawisko.
  Zawiera celową niejasność (6.2) i nadpisanie scenariusza (7.1).
- `minigame/phenomena.yaml`: mapa reguła → zjawiska. Na niej opiera się pokrycie zestawów logic, digitalization,
  editorial i translation.
- `minigame/gold/` (od M3): złote modele kolejnych etapów.
- `minigame/mutations/` (od M4): operatory mutacji i oczekiwane wykrycia.

Teksty chronione (instrukcje wydawców) nie wchodzą do tego katalogu. Prywatne zestawy żyją w `private/bench/` (gitignored).
