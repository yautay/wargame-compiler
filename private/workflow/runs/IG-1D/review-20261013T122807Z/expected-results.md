# Independent IG-1D expectation provenance

The authoritative IG-1D card/queue requires deterministic persisted identities, unambiguous anonymous rematches, explicit ambiguous gaps, many-to-many origin bindings, precise references and closure, and no inherited semantic acceptance. The approved source-export profile is a separate exact contract with only explicit version identification and null canonical run clocks; its root ID/title, 14 version constants and two run-clock shapes were independently compared against a transformed deep copy of the original schema. Every other schema field/invariant is identical. Operator approval references the exact proposal and patch hashes; it is not semantic approval.

Mutation expectations use invented values and independent histories. Reorder/file move leaves unchanged entities unchanged. A unique name with a revised body supports correction; an unchanged distinct body with a new name supports an unambiguous rename when no evidence points elsewhere. The contradictory two-term counterexample has two equally source-compatible histories: editing/exchanging definitions while keeping terms, or exchanging names while keeping definitions. No declared IDs or explicit decision selects between them. A heuristic's execution order is not evidence for one history. The test therefore requires gaps and all candidates, not guessed IDs.

The explicit-decision conflict oracle combines a new-child split instruction with a hint to preserve an unrelated existing ID at the same exact child locator. These decisions are mutually exclusive. It permits either a ValueError rejection or an explicit unresolved gap, but forbids silently discarding a recorded instruction. Keyed identical children, disjoint many-to-many hints, reorder/edit replay and exact historical split revisions have independent positive controls.

The direct-reference oracle uses the actual active persisted identity returned by a prior reconciliation, not a hard-coded allocation number. A raw exact active ID has an unambiguous current target independently of aliases. It needs no semantic interpretation. External alias collisions, wildcard/subpoint unresolved status, explicit justified scopes and both-endpoint relationship resolution have separate controls. Rule/procedure cycles remain allowed diagnostics, not a DAG validation error.

Closure tests deliberately tamper a hash, a selected revision and the approved null clock shape. They do not use successful validation alone as the only oracle. Publication controls compare canonical package identity and bytes, retain distinct operational sidecars and preserve corrupt packages without repair. No accepted game answer or publisher legality was used.
