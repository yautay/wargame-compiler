# Synthetic source-contract cases

All content is invented and public. No fixture is a SPQR rule, source transcription,
human acceptance or executable game. `catalog.json` defines expected validity and report
facts, with independent references to the active architectural requirements.

The base case deliberately combines complete import, two represented transcription
regions, an accepted metadata record scoped to one condition, an opaque effect, a missing
unit, and missing loop termination. It is structurally valid and blocked for execution.
Negative cases alter a single target invariant; positive variants preserve historical
pins while changing selections to exercise freshness. The byte/hash tests use explicit
serialization vectors independently of these frozen files.
